Demo & follow-along

Acht oefeningen om live te projecteren en samen te typen. Elke oefening: doel · wat jij zegt · stappen · starter · oplossing · stretch.

Live demo Follow-along Starter + oplossing ~5–12 min / stuk
Hoe gebruik je dit in de les?
  1. Projecteer deze pagina (of één starter-HTML in de editor).
  2. Leerlingen openen het bijbehorende bestand in starters/ (Live Server).
  3. Jij doet de stappen hardop; zij typen mee. Pauzeer na elke stap.
  4. Toon kort het verschil in DevTools device-mode (320 / 768 / 1200).
  5. Stretch = snelle leerlingen of huiswerk. Oplossingen staan in oplossingen/.
Tip
Geel (zo) = exacte waarden om over te nemen. Laat leerlingen eerst zelf nadenken vóór je de code toont.

Oefening 01 · Fundamentals

Viewport aan / uit

± 5 min Demo (jij typt) Instap
Doel Leerlingen zien met eigen ogen waarom <meta name="viewport"> verplicht is op mobile.
💬 Zeg dit
Script “Mobiele browsers doen alsof ze ~980px breed zijn en zoomen uit — tenzij wij dat afzetten. Ik toon nu hetzelfde bestand mét en zonder viewport-meta.”
S Stappen (live)
  1. Open starters/01-viewport.html in de browser + DevTools → device toolbar → iPhone / 320px.
  2. Toon: tekst is piepklein, layout “desktop-achtig ingezoomd”.
  3. Haal de commentaar-strepen weg rond de viewport-meta (of plak hem erin).
  4. Refresh: layout volgt device-width. width=device-width, initial-scale=1.0.
  5. Vraag de klas: “Wat zou er gebeuren als we maximum-scale=1 zetten?” → a11y-discussie (liever niet).
{ } Kerncode
in <head>exact
<meta name="viewport"
      content="width=device-width, initial-scale=1.0">

Oefening 02 · Mobile-first

Stack → rij

± 8 min Follow-along Basis
Doel Mobile-first patroon: basis = kolom, vanaf breakpoint = rij met min-width.
💬 Zeg dit
Script “We schrijven eerst voor de smalste layout. Grotere schermen krijgen extra regels — niet andersom. Dat is mobile-first.”
S Stappen (samen typen)
  1. Open starters/02-mobile-first.html. Drie boxes staan al in de HTML.
  2. Op .row: display: flex, flex-direction: column, gap: 12px.
  3. Voeg toe: @media (min-width: 700px).
  4. Daarin: .row { flex-direction: row; } en .row > * { flex: 1; }.
  5. Test: versmal/verbreed het venster of gebruik device-mode.
{ } Doel-CSS
CSS
.row {
  display: flex;
  flex-direction: column;
  gap: 12px;
}

@media (min-width: 700px) {
  .row { flex-direction: row; }
  .row > * { flex: 1; }
}
+ Stretch
Vanaf 1000px: gap: 24px en een lichtere achtergrond op de cards.

Oefening 03 · Breakpoints

Kleur per zone

± 8 min Follow-along Basis
Doel Drie min-width-zones zichtbaar maken. Breakpoints “voelen”, niet uit het hoofd leren.
💬 Zeg dit
Script “Een breakpoint is geen magisch getal van Apple — het is de breedte waar jóuw layout breekt. Wij forceren nu drie zones met kleur zodat je de sprong ziet.”
S Stappen
  1. Open starters/03-breakpoints.html.
  2. Basis .zone: achtergrond #ff3b00, tekst wit, padding 24px.
  3. Vanaf min-width: 600px: achtergrond #0047ff.
  4. Vanaf min-width: 1000px: achtergrond #00c853, tekst zwart.
  5. Optioneel: met ::after de labeltekst wijzigen (phone / tablet / desktop).
+ Klassikale vraag
“Waarom min-width en niet max-width als we mobile-first werken?”
Antwoord
Basis = kleinste scherm. Je voegt toe naarmate er meer ruimte is.

Oefening 04 · Flexbox

Cards die wrappen

± 10 min Follow-along Midden
Doel Het patroon flex-wrap + flex: 1 1 …px — responsive cards zonder media query.
💬 Zeg dit
Script “Soms heb je geen breakpoint nodig. Flex kan zelf beslissen hoeveel kaarten naast elkaar passen. flex: 1 1 180px betekent: basis ~180px, daarna groeien en krimpen.”
S Stappen
  1. Open starters/04-flex-cards.html (6 cards staan klaar).
  2. .cards: display: flex, flex-wrap: wrap, gap: 12px.
  3. .card: flex: 1 1 180px, padding, border, achtergrond.
  4. Versmal het venster: 1 → 2 → 3 kolommen vanzelf.
  5. Experiment: verander 180px naar 240px — minder kolommen.
{ } Kern
CSS
.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 12px;
}
.card {
  flex: 1 1 180px;
}
+ Stretch
Voeg min-height: 100px toe en centreer de tekst met flex op de card zelf (display:flex; align-items:center; justify-content:center).

Oefening 05 · CSS Grid

auto-fit + minmax

± 10 min Follow-along Midden
Doel Het “holy grail”-grid: repeat(auto-fit, minmax(…, 1fr)) — responsive zonder MQ.
💬 Zeg dit
Script “Grid is 2D. Met auto-fit en minmax zeg je: zoveel kolommen als er passen, elk minstens X pixels, en ze delen de rest gelijkelijk. Eén regel. Geen media query.”
S Stappen
  1. Open starters/05-grid-autofit.html.
  2. .grid: display: grid.
  3. grid-template-columns: repeat(auto-fit, minmax(160px, 1fr)).
  4. gap: 16px.
  5. Vergelijk met oefening 04: zelfde effect, andere tool. Wanneer grid vs flex?
Discussie (2 min)
Flex = 1 richting (rij of kolom). Grid = rijen én kolommen tegelijk. Cards in een gallery: beide kunnen — grid blinkt uit bij echte 2D.

Oefening 06 · Navigatie

Hamburger → horizontale nav

± 12 min Follow-along Midden+
Doel Klassiek responsive-nav patroon: toggle op mobile, horizontale links vanaf tablet.
💬 Zeg dit
Script “HTML eerst: knop + nav. CSS: op mobile verbergen we de links tot .open. Vanaf 800px tonen we altijd een rij en verbergen we de knop. Mini-JS voor de toggle — later netter met aria-expanded.”
S Stappen
  1. Open starters/06-nav.html — structuur staat er al.
  2. Mobile: .links { display: none; } en .links.open { display: flex; flex-direction: column; }.
  3. JS: knop togglet class open op .links.
  4. MQ min-width: 800px: knop display: none, links altijd display: flex; flex-direction: row.
  5. Test beide breedtes. Bonus: aria-expanded op de knop zetten.
Let op
Nav nooit “weggooien” zonder alternatief. Keyboard- en screenreader-gebruikers moeten erbij kunnen.

Oefening 07 · Modern CSS

Fluïde titel met clamp()

± 8 min Follow-along Midden
Doel clamp(min, preferred, max) toepassen zodat type vloeiend schaalt zonder harde MQ-sprong.
💬 Zeg dit
Script “Drie waarden: nooit kleiner dan min, nooit groter dan max, daartussen een formule met vw. Ideaal voor hero-titels. Body-tekst blijf je eerder in rem houden.”
S Stappen
  1. Open starters/07-clamp.html.
  2. Op h1: font-size: clamp(1.5rem, 4vw + 1rem, 3.5rem).
  3. Op .hero: padding: clamp(1rem, 5vw, 3rem).
  4. Versleep het venster — vloeiende schaal, geen sprong.
  5. Vergelijk met een oude MQ-aanpak (optioneel kort tonen).
{ } Kern
CSS
h1 {
  font-size: clamp(1.5rem, 4vw + 1rem, 3.5rem);
}
.hero {
  padding: clamp(1rem, 5vw, 3rem);
}

Oefening 08 · Challenge

Mini landing page

± 12–20 min Challenge / duo Integratie
Doel Alles combineren: viewport, mobile-first nav/hero, fluïde type, responsive grid met projecten.
💬 Zeg dit
Script “Dit is jullie integratie-oefening. Starter heeft HTML-skelet en lelijke vaste CSS. Jullie maken hem responsive. Checklist op het bord — 12 minuten, daarna 2 duo’s showen.”
S Must-have checklist
  1. Viewport-meta staat correct.
  2. Geen vaste width: 1100px meer — wel width: 100% + max-width.
  3. Hero-titel met clamp().
  4. Projecten in grid of flex-wrap (auto-fit of flex 1 1 …).
  5. Nav: stacked op mobile, rij vanaf ~800px (toggle mag, is bonus).
  6. Geen horizontale scrollbar op 320px.
Review-rondje
2 min per duo op projector: “Wat was jullie breakpoint-keuze en waarom?”
