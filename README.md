## Starten

1. Open `follow-along/index.html` via Live Server (lesbord / projector).
2. Leerlingen openen het bijbehorende bestand in `starters/`.
3. Oplossingen staan in `oplossingen/` (niet meteen delen).

```bash
cd responsive-design
python3 -m http.server 8091
# → http://localhost:8091/follow-along/
```

## Snel lesplan (45–50 min)

1. **5 min** — Ex 01 viewport demo  
2. **8 min** — Ex 02 of 03

4. **12 min** — Ex 06 of 07
